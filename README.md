# OurShelf

A mini virtual bookshelf created for two friends to share their readings, keep track of books, and exchange recommendations in a simple and personal way.

This project was born from the idea of turning our reading habits into something more visible, organized, and shared — like a bookshelf/diary but digital.

---

## Features

- Add books and control who's reading or will read It
- Share comments about the books
- Track reading percentage (manually) 

---

## Project Goal

The main goal of this project is to:

- Register and organize our readings  
- Encourage consistent reading habits  
- Share opinions and book discoveries  
- Maintain a shared virtual bookshelf, even at a distance
